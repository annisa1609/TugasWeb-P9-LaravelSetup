## Cara Menjalankan Project

1. Pastikan PHP, Composer, dan MySQL sudah tersedia.
2. Buka terminal pada folder project.
3. Jalankan perintah `composer install` jika dependency belum tersedia.
4. Siapkan file `.env` berdasarkan `.env.example` dan sesuaikan konfigurasi database.
5. Jalankan migrasi database dengan `php artisan migrate` jika diperlukan.
6. Jalankan server menggunakan `php artisan serve`.
7. Buka alamat `http://127.0.0.1:8000` pada browser.
